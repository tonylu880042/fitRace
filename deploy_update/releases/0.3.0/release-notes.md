# FitRaceStudio 0.3.0

## 更新內容

### 比賽活動
- 事先報名：Game Admin 匯入名單 CSV，依站位數自動分組，一鍵「載入下一組」；支援缺席、重新排入、現場報名，並防止連按跳過未比賽的組別。
- 接力賽：同一台跑步機多人輪流，依距離平均分棒，自動換棒並記錄每棒分段時間；可從名單依隊伍載入。
- 男子組／女子組分組；紀錄牆依組別分開排名，同一人只取最佳成績。
- 完成時間改以過線前後兩筆數據內插，跨組比較更公平。
- Game Admin 可下載全部比賽成績 CSV（Excel 可直接開啟中文）。
- System Admin 可清除比賽紀錄（需輸入管理員密碼，清除前自動備份）。
- 允許匿名參賽（不填姓名）。

### 大螢幕
- 跑步機顯示每公里配速，並依快慢變色發光；最快配速顯示 🔥，賽道模式加速度拖尾。
- 站位少（1–4 台）時自動放大排行榜字級與卡片。
- 接力賽顯示棒次、目前跑者與換棒提示；未完賽顯示「未完成」而非錯誤秒數。
- 顯示無法開賽的原因。

### 課程模式
- 新增 Class Admin 與課程看板：課表編輯、目標功率、換站段落、強度曲線、段落提示音。

### 系統
- OTA 套用後會檢查 Hub 健康狀態，失敗自動回滾。
- Edge 操作頁手機優化、多語系、單台重新連線。
- 修正 MQTT broker 重啟後 Hub 不再接收數據等穩定性問題。

## 注意

- **相依套件：** 本版 Hub 需要 `segno` 與 `websockets`。OTA 只替換程式碼、不安裝套件；若 Hub 的 Python 環境缺少任一套件，更新後 Hub 無法正常啟動或大螢幕不會即時更新（前者會觸發自動回滾）。套用前請先確認已安裝（`scripts/wheels/` 內有 segno 離線安裝檔）。
- `manifest.json.sig` 必須使用正式 release private key 簽章後才能上雲。
- 已安裝 0.2.1 以下版本的 Hub 會以 manifest 的 Hub version `0.3.0` 判定有新版本。
- Edge artifact 不含 `edge_node/config.json`，避免覆蓋現場設定；Edge 仍維持 LAN／手動部署流程。
