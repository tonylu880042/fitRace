# FitRaceStudio 0.4.0

## 更新內容

### 比賽活動
- 多器材分組賽：同一場比賽可混合不同器材（例如跑步機與飛輪），每組各自設定目標、各自排名與自動結束；Game Admin 可編輯分組並檢查各組站位是否就緒。
- 總排名：大螢幕待命時改為單一頁面，列出本次活動（同距離、同棒數）所有組別的整體排名，不再輪播前三名；男女組分開排名，同隊／同人只取最佳成績。
- Game Admin 新增「清除成績」：緊鄰「下載成績 (CSV)」，兩步確認防誤觸，清除前自動備份；未設定管理員密碼也可使用。
- Game Admin 新增「清除名單」（兩步確認，不影響成績）與「取消目前這組」（已載入但尚未比賽的組別退回待比賽最前面，可重新載入）。

### 大螢幕
- 可從 Game Admin「即時呈現」分別隱藏大螢幕上的「報名 QR Code」與「Game Admin QR Code」，設定會保存。
- 經典排行榜進度條加粗、站位少時加倍高度，前緣加上脈動效果。
- 多器材分組賽依器材分區顯示排名，紀錄牆顯示各組最新成績。

### 系統
- System Admin 的 Hub 更新改為一鍵完成（檢查、下載、套用）。
- 修正啟動更新服務時會卡住的問題。

## 注意

- **相依套件：** 與 0.3.0 相同，Hub 需要 `segno` 與 `websockets`，本版沒有新增套件。
- 清除成績會把 `race_results.jsonl` 改名為 `.bak-時間` 備份；清除名單**沒有備份**，清除前請保留名單 CSV。清除成績的 API 在未設定 `FITRACE_ADMIN_TOKEN` 時不再要求密碼（有設定時仍需要）。
- `manifest.json.sig` 必須使用正式 release private key 簽章後才能上雲。
- 已安裝 0.3.x 的 Hub 會以 manifest 的 Hub version `0.4.0` 判定有新版本。
- Edge artifact 不含 `edge_node/config.json`，避免覆蓋現場設定；Edge 仍維持 LAN／手動部署流程。
